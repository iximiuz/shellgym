# Success and Failure

Commands don't always work - and that is fine. In this module you will
break things on purpose, read the complaints, and learn the shell's
secret bookkeeping: every command reports whether it succeeded, and the
shell lets you *chain* commands based on that report.

This is the part of shell fluency that turns single commands into
little plans: "do this, and if it worked, do that - otherwise do the
backup thing."
