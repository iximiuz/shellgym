# Two Kinds of Commands

Where do commands actually come from? Most are small **programs**
stored on disk - `whoami`, `date`, and `seq` are all files that the
shell finds and runs for you. But a handful of commands are **built
into the shell itself**: no file involved, the shell just does the work
on the spot. Those are called **builtins**.

You rarely need to care which kind you are running - but knowing the
difference explains a lot of Linux behavior, and this short module
shows it to you first-hand.
