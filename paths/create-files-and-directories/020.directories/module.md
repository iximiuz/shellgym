# Directories

The `mkdir` command ("make directory") takes a path and creates a
directory there. Like `touch`, it accepts several paths in one command,
absolute or relative. By default it creates one level at a time: the
parent of the new directory must already exist. There is an option
that creates the missing parents as well, and you will learn how to use both modes in this module.

This module uses the same `~/projects` tree as the previous one. Every
unit recreates it if needed.
