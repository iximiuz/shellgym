# Put It Together

The last module combines creating files and directories with the
listing skills and the patterns from
[List Files and Use Patterns](https://labs.iximiuz.com/shell-gyms/list-files-and-use-patterns),
in small jobs of the kind you will do on any Linux machine: refresh a
group of files with one pattern, find the oldest or the largest file
and act on it, and prepare a hidden workspace.

The units use the `~/projects` tree from the previous modules, and the
final unit is a lap through everything you have learned in this gym.
