# Read the Manual

The `--help` option gives you the summary. The full documentation lives in the
manual pages, and nearly everything installed on a Linux machine ships
one: programs, file formats, and even the shell's own syntax.

The command is `man`. It opens the page in a pager, a program that
shows long text one screen at a time and waits for your keystrokes to
scroll, search, or quit. In this module you will read pages, search
inside them, and search across all of them when you only remember what
a command does.
