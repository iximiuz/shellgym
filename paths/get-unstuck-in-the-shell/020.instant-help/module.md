# Help Is One Flag Away

Nobody memorizes every option of every command. Experienced users ask
the command itself. Most programs print a summary of what they do and
which options they accept when run with the `--help` option. Builtins
have no program behind them, so the shell provides its own
documentation command for them, the builtin `help`.

Each unit in this module gives you a small job that needs an option
you might not know yet. Print the help, find the option in it, and run
the command with it. The last two units do the same for a builtin and
show what to do when a name is both a builtin and a program.
